Gold review

Hover over a model's answer to see the text it quoted and its reasoning. Click a highlighted passage to jump to its item.

How to review

  1. Work document by document. The left list shows how many answers in each report still need you. Next to review (n) jumps to the next one anywhere.
  2. Settle the item list first. Each card is one specimen or test, as the models' answers were aligned. When not every model found an item, the card asks Is this a real, distinct item?
    • One model counted a part twice → answer No on the duplicate.
    • One part appears as two cards (the models' answers were not aligned) → keep the better card, answer No on the other, and fix the kept card's fields.
    • A part no model found → + Add specimen at the bottom. Select its text in the report, then click Use selected text.
  3. Then the fields. Each row shows each model's answer. Green means it matches the current gold value. Click an answer to adopt it, or set the value yourself. Changing a value marks it reviewed. If the pre-filled value is right, click ✓ (or press y on the highlighted row).
  4. Badges: models disagree not all found it spot check. A spot check is a random sample of answers all the models agreed on, used to estimate errors they share. Rows without a badge are consensus. You can still edit them; hide them with the toggle at the top.
  5. (none) means not stated / empty. List fields (several values) use toggle chips or one value per line.
  6. Everything saves automatically to verdicts.json. When done: python -m hnc_extract gold-import --dir <dir>.

Keys: n next to review · y confirm highlighted row and go to the next · [ ] previous / next document · h hide/show consensus rows · ? this help · Esc close

Rulings so far: "consistent with" / "compatible with" = affirmed. A cytospin preparation is the specimen, not an ancillary test.
